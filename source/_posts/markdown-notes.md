## 先把结构写出来

每篇笔记先说明目标，再写过程，最后记录结果和遗留问题。标题用来组织内容，段落负责解释细节。

## 常见写法

| 内容 | Markdown 写法 |
| --- | --- |
| 加粗 | `**重点内容**` |
| 行内代码 | 使用一对反引号包围代码 |
| 二级标题 | `## 标题` |
| 引用 | `> 引用内容` |

### 列表

1. 说明遇到的问题。
2. 记录使用的环境与条件。
3. 写下解决步骤和验证结果。

### 代码块

下面是一段简单的 JavaScript 示例：

```javascript
const notes = ['记录问题', '整理过程', '验证结果'];

for (const note of notes) {
  console.log(note);
}
```

### 引用与重点

> 一篇有用的笔记，应该让未来的自己也能看懂。

可以用 **加粗** 标出关键结论，用 `行内代码` 表示命令、文件名或参数。

## 发布前检查

- 标题能否说明文章内容？
- 代码块是否注明语言？
- 图片能否正常显示？
- 是否包含不应公开的个人信息？

完成这些检查，再把文章发布出去。
